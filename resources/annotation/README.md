# resources/annotation/

Tables from the GTF (rule `annotation_tables`, `workflow/scripts/gtf_to_tables.py`):

- `genes.tsv`: gene_id, gene_name, gene_biotype, chr, start, end, strand, tss
- `transcripts.tsv`: transcript_id, gene_id, transcript_name, transcript_biotype, chr, start, end, strand, tss, length, n_isoforms_of_gene
